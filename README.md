# Lexi · macOS 英语学习软件

Lexi 是一款面向 macOS 的英语词汇学习与阅读辅助应用。当前源码与已发布版本为 **3.0.4**，支持 Apple Silicon（M 系列）和 macOS 12 或更新版本。

[下载已发布的 Apple Silicon 安装包（DMG）及 SHA256 校验文件](https://github.com/DespairJasper/lexi-macos/releases) · [查看 3.0.3 旧版](https://github.com/DespairJasper/lexi-macos/releases/tag/v3.0.3)

## 特色功能

- **离线查词与个人词汇档案**：内置 59,026 条离线词典，支持释义、音标、发音、收藏、生词整理、复习、备份与恢复。查词无需网络或 AI 服务。
- **IELTS 专题与拼写训练**：包含 IELTS 词汇专题、章节学习、听力考点词、淡写与默写练习；可选择练习内容、数量和顺序，并由应用自动发音。
- **三次认识记忆轮次**：一个词连续被评为“认识”三次才完成记忆；“模糊”会在本轮稍后再出现，“忘记”会重置进度。每一遍内随机排序，并显示三格记忆进度。
- **每日学习计划**：在独立导航中自定义多个计划，按词书、单元或词条选词，设置每日词数与顺序并查看预计天数；通过单词卡学习，每轮结束可对全部词或忘记词进行淡写 / 默写。计划可调整、停止、恢复，停止后可删除。
- **跨应用快捷小卡片**：在浏览器、文献或编辑器中选中文字后，可用 `⌥D` 查词、`⌥A` 翻译句子、`⌥S` 收藏金句；也可在卡片里手动输入。快捷键可在设置中修改。
- **金句本**：保存原文、译文、来源和备注，支持搜索、编辑、导出及备份。
- **流式 AI**：为翻译或词汇辅助配置自己的服务地址、模型和 API Key；支持流式显示。API Key 由 macOS 钥匙串保存，AI 请求发送至用户自行配置的服务。
- **液态玻璃外观**：支持液态玻璃与毛玻璃外观，并可调整效果强度；也提供高对比度、不透明背景和减少动态效果等选项。
- **本地优先**：个人词汇档案与金句保存在本机。离线查词不依赖账号、网络或 API Key。

## 使用前需要准备

### 普通使用者

1. 一台搭载 Apple Silicon 的 Mac，系统为 macOS 12 或更新版本。
2. 下载约 488 MB 的 DMG，并留出足够空间将应用复制到“应用程序”文件夹。
3. 若要使用跨应用快捷小卡片，请在 macOS 系统设置中为 Lexi 授予**辅助功能**权限。未授予时仍可在卡片中手动输入文字。
4. AI 功能是可选项。如需使用，请自行准备可访问的 API 地址、模型名称、API Key 和网络连接；服务商可能按其规则收费。不使用 AI 不影响离线查词与本地学习功能。

### 安装步骤

1. 从上方发布页下载已发布的 `Lexi-3.0.4-macOS-arm64.dmg`。
2. 在终端进入 DMG 所在目录，运行 `shasum -a 256 -c Lexi-3.0.4-macOS-arm64.dmg.sha256`，确认校验通过。
3. 打开 DMG，将 Lexi 拖入“应用程序”，推出磁盘映像后再启动应用。
4. 首次使用跨应用选词时，按系统提示授权辅助功能。

**关于首次启动：** 当前 DMG 使用本机固定的自签名证书，未使用 Apple Developer ID 签名，也未经过 Apple 公证。macOS 可能显示安全提示。请先确认下载来源并核对 SHA256；如果系统或组织策略阻止运行，请遵循设备管理员的安全策略。

## AI 与隐私

API Key 需要由使用者在 Lexi 设置中配置，并保存在 macOS 钥匙串中。AI 相关文本会发送至设置的服务地址；请按该服务的隐私政策选择是否使用。项目发布源码与 DMG 不包含个人 API Key、个人中转地址或本机签名私钥。

## 从源码构建

构建环境需要 macOS、.NET 8 SDK 和联网下载 NuGet 依赖；安装包构建还需要 Python 3.10 或更新版本及 macOS 自带的磁盘映像工具。发布副本不包含 SDK；可使用 `scripts/install_dotnet.sh` 安装项目本地 SDK。

```bash
python3 scripts/stable_signing.py setup
bash scripts/package_app.sh --rid=osx-arm64
bash scripts/package_dmg.sh
```

第一次签名构建前运行 `setup`，在当前 Mac 上创建本地签名身份；之后会复用该身份。签名私钥保留在本机钥匙串，不应复制到仓库或分享给他人。日常开发无需签名身份即可用 .NET 构建项目。
