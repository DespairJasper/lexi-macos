# Lexi 3.3.1 · macOS

发布日期：2026-10-16 · 适用 Apple Silicon（M 系列）Mac、macOS 12 或更新版本

## 一起学习 · 续命局

3.3.1 加入「一起学习」。你和一位好友各自完成当天的学习计划，就能把共同连续天数续下去；任何一方未完成，在补传等待结束后确认中断。每段关系独立计算，同一天完成自己的计划可以同时支持多位好友。

- **双人邀请，没有群组。** 应用内生成 24 小时一次性邀请码，由你自己发给对方；对方登录后兑换、看到你的昵称，再显式接受或拒绝。没有公开用户目录、全站头像列表、排行榜或自动站外消息。
- **逐好友、分方向的分享开关。** 新学 / 复习词数、预测曲线与每日有效时长默认开启，可以针对每位好友分别关闭。关闭即刻撤销授权并清空本机保存的对方数据；对方是否分享由对方独立设置，不受你的开关影响。
- **计划与词条不上传。** 云端只接收当日达标摘要与 121 点曲线摘要；计划名称、每日配额、具体词条、完成时刻与本地路径都留在本机。
- **头像私有。** 头像存放在私有存储，仅本人与已接受好友可读；上传时自动居中裁剪为 256×256 的 WebP，不超过 200 KB，重编码不保留拍摄信息。

## 判定口径

- **按北京时间划分学习日。** 00:00:00（含）到次日 00:00:00（不含）；与设备时区、夏令时无关。
- **完成自己的当日计划才算达标。** 当日目标跟随计划的真实当前状态：停止计划立即从当日要求中移除，恢复或调整数量也立即更新。没有启用计划、当日目标为 0，都不会自动达标。
- **学习日结束后，离线补传等待 72 小时。** 截止前缺少云端确认时显示「待确认」，不会因为本机没上传就在 00:00 判成中断。截止时间以服务端接收时间为准。
- **连续天数只由云端确认。** 客户端只能提交摘要或请求重开一局，不能直接写连续天数。

## 好友详情

- **预测曲线对照。** 自己与全部已授权好友的最新曲线叠加显示，每条可单独隐藏，各自标注样本数。曲线是记忆模型的预测，不是记忆能力排名。
- **过去一周。** 最近 7 个完整学习日分两幅图：有效学习时长与学习词数。缺失或未授权日期断线，不补成 0；绑定当天只统计绑定之后的时段并明确标注。
- **一起苟过的日子。** 本次成为好友以来的累计共同成功天数（跨局累计、同日去重、云端确认），以及可选时间窗内「共同成功日」与「没有共同成功日」的本人学习对照。待确认与无法核对的历史日期不计入任何一组；这是描述性对照，不是因果结论。

## 隐私与数据

- 完整逐词历史、词库、音频、FSRS 状态、个人模型参数、金句、设置与计划内容都不作为社交数据上传。
- 不登录时原有离线学习完全可用，不会自动建立云端账号或社交队列。
- 学习数据与社交队列分开存放；云端不可用时学习照常，摘要留在本机等待重试。

## 升级与回滚

- 沿用原数据目录、数据库 schema、签名身份与自动更新检查；覆盖安装后继续正常使用。
- 原 `~/Library/Application Support/Lexi/` 下的学习数据不被迁移或改写；社交状态保存在独立的 sidecar 中。
- 旧版不包含新增专题；如确需回退，请先保留完整数据备份。旧版无法展示新词书和好友功能。

## 已知边界

- 本版社交功能只做了隔离环境下的自动化验收。**尚未用真实 GitHub 账号完成端到端 OAuth 登录、上传与云端存储字节回收的真机验收**，因此请以「好友功能可用但首版」对待。
- 首版每人最多 20 段有效关系、每日 10 次邀请，这是两两模型下的额度保护，不是小队功能。
- 摘要机制能防重复提交和客户端伪造连续天数，但**不能密码学地证明你真的背了词**，也不能完全阻止恶意修改本机时间。本玩法不做排行榜。

## 保留

- 计划来源的复习卡词条补全、评分后「下一词」点击与空格键修复（3.2.3）。
- 存储修复、冰川蓝界面、双语学习统计、活动图与遗忘曲线动画（3.2.0–3.2.2）。

## 七大考试专题与完整词书

考试专题包含 IELTS、四级、六级、考研、GMAT、TOEFL、GRE。IELTS 保留雅思词汇真经、听力 179 考点词、阅读同义替换、英美拼写规范、写作 100 句、语法与听力资料。其余六类共 20 本词书、66,974 条按书独立标识的词条，完整书名与各书条目数见 [README 考试与词书目录](../../../README.md#考试专题与完整词书目录)。

学习计划支持「考试专题 → 书本 → 单元」三级选择和整本词书；专题页创建计划默认带入当前选择。切换中文 / English 时保留考试、词书与单元选择。各书可使用单词卡认词、淡写、默写与错词练习，并接入今日重逢及 FSRS 长期复习。

新词书沿用已有基础书的词身份与计划引用，新增书本的未完成轮次分别保存。复习时按来源补全单词、音标、释义与已有例句，保留此前评分后点击与空格换卡修复。

第三方词书固定来源、原始文件 SHA256 与去重说明保存在导入清单中，来源授权见 [词书声明](../../../lexi_avalonia/Notices/KAJWEB-DICT-SOURCE.md)。

## 发布验证

本版最终多词书更新采用增量验证：复用前一轮已通过的未变模块检查，并验证多书籍、单元联动、计划选书、书级身份与今日重逢。发布时另核对安装应用与 DMG 中的版本、程序集、固定签名、隐私和 SHA256；不是重新宣称所有模块都在最后一轮完整重跑。

下载 `Lexi-3.3.1-macOS-arm64.dmg` 与 `.sha256`，在下载目录运行：

```bash
shasum -a 256 -c Lexi-3.3.1-macOS-arm64.dmg.sha256
```

确认 `OK` 后，用 `⌘Q` 正常退出旧版，将 Lexi 拖入应用程序替换。个人词库、计划、金句、学习历史、时长与记忆模型保留在应用包外；采用自定义档案目录的用户继续使用原目录。
