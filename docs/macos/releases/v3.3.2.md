# Lexi 3.3.2 · macOS

发布日期：2026-10-19 · 适用 Apple Silicon（M 系列）Mac、macOS 12 或更新版本

## 修复好友信息显示

好友目录、邀请状态和个人昵称 / 头像现在分别读取。个人资料或头像暂时无法访问时，已由云端确认的好友仍会显示；邀请读取失败也不会清空好友列表。只有好友目录本身无法从云端确认时，界面才撤销依赖该授权的缓存与曲线，并提示稍后重试。登录状态和本机学习数据不会因资料读取失败而改变。

## 好友详情界面

- 把「一起苟过的日子」整理成指标卡片和分段统计卡，减少连续多行说明文字。
- 增加最近 30 个完整学习日的横向卡槽。点选日期可查看本人学习时长、词数和云端确认状态。
- 调整记忆曲线图与周统计图的绘图区、坐标标签及单位位置；图例显示各条曲线的样本数，并使用对应曲线颜色。
- 曲线仍表示 FSRS 模型预测，不用于记忆能力排名；未授权、待确认或未知日期不会被补成零。

## 数据与兼容性

本版不改变词汇库、学习记录、计划、个人 FSRS 参数、登录态、社交 sidecar、云端 API/RPC 契约或数据目录。直接覆盖安装后继续使用现有本地数据。资料读取失败不会触发数据迁移或重置。

## 安装

下载 `Lexi-3.3.2-macOS-arm64.dmg` 与 `.sha256`，在下载目录运行：

```bash
shasum -a 256 -c Lexi-3.3.2-macOS-arm64.dmg.sha256
```

确认 `OK` 后，先用 `⌘Q` 正常退出 Lexi，再将安装包中的应用拖入“应用程序”并确认替换。用户数据位于应用包外，覆盖安装会沿用原目录。
