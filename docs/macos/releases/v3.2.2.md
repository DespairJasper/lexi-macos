# Lexi 3.2.2 · macOS

修复已同步计划快照及高频全量备份引起的磁盘空间异常增长。

## 修复

- JSON 文件写入成功并得到 SQLite 确认后，回收该条内部完整快照；未完成待办和故障重试保留，跨存储重放协议不变。
- 自动清理3.2.1遗留的已确认快照；当空闲页至少32MiB且至少占数据库25%时，用SQLite VACUUM回收空间。维护失败保留数据，下次启动重试。
- 旧版快照严重膨胀或上次压缩中断留下大量空闲页时，先保留一份验证通过的历史备份并释放重复副本，再生成维护前备份；整理成功后只保留干净副本，避免旧备份占满磁盘阻止启动。
- 常规自动备份每15分钟最多一次；启动、维护和手动备份立即保存完整副本。完整备份上限20份。预算根据主库大小动态调整，常规情况下主库与备份合计控制在2GB（20亿字节）内；已积累历史时保留多个有效完整恢复点。大数据库与两个完整恢复点合计超过2GB时，最多保留最近两份完整备份，学习历史与个人记忆数据不裁剪。
- 创建新副本前验证源库和独立旧副本，预留复制容量后轮转；新副本验证、flush与原子发布后再次核对预算。主库验证失败时保留全部原恢复点，复制失败时保留验证有效的旧副本。
- 自动备份间隔内复用时先检查文件数量与大小，仅需轮转时验证主库并检查历史副本；备份删除失败按已有警告机制报告，避免静默突破限制。
- 完整备份验证覆盖原始v2记忆表，缺失FSRS状态或个人参数表的副本不能充当恢复点；兼容旧版同schema的完整备份。
- 首次使用及旧快照整理后的历史恢复点随正常备份逐次积累。
- 仅清理严格匹配软件生成名称的已完成备份；任意用户文件及符号链接不参与淘汰。
- 安装前一致性备份覆盖学习时长JSON和已有侧车备份。

## 安装与数据

下载 `Lexi-3.2.2-macOS-arm64.dmg` 和配套 `.sha256`，运行：

```bash
shasum -a 256 -c Lexi-3.2.2-macOS-arm64.dmg.sha256
```

确认OK后先用⌘Q正常退出旧版，再拖入应用程序替换。沿用 `~/Library/Application Support/Lexi/`、数据库schema和签名身份。所有词汇、学习计划、学习轨迹、复习记录、时长、金句、设置及记忆模型均保留。FSRS与Context逻辑、自动更新检查及其余交互沿用3.2.1。

适用于Apple Silicon、macOS12+，包含运行环境、离线词典与本地optimizer。沿用固定分发签名，尚未采用Developer ID与Apple公证。
