# Lexi 3.2.0 · macOS

冰川蓝更新重新整理学习计划与每日练习入口，并新增学习统计。

- 今日计划统一显示词汇总数与完成进度，原计划操作改为条状列表；已完成计划汇总学习天数与去重词数。
- 首次学习完成后按钮变灰；今日复习直接进入回忆阶段，复习与拼写可反复进入，不改写首次学习进度。
- 统计分开显示初学、复习、拼写有效时长，包含词汇、天数、连续学习、峰值、易忘词 TOP 50 与时长趋势。
- 日度活动图用色深表示时长；周度、月度与累计用方格柱表示聚合时长，切换时从左到右逐渐显示。遗忘曲线同样逐渐绘制，并用通俗文字区分模型预测、真实观察及参数含义。
- 新增界面与解释随中英文同步切换。顶部四项指标在非全屏窄窗口中仍为一行，字号按窗口宽度调整。
- 首页去掉品牌图标及左上角品牌文字，进度条使用统一冰川蓝。页面和浮层使用平滑过渡，尊重减少动态效果设置。

## 安装与数据

下载 `Lexi-3.2.0-macOS-arm64.dmg` 及配套 `.sha256`。进入下载目录运行：

```bash
shasum -a 256 -c Lexi-3.2.0-macOS-arm64.dmg.sha256
```

确认 `OK` 后打开 DMG。先用 `⌘Q` 正常退出旧版，再将 Lexi 拖入应用程序替换。数据目录仍为 `~/Library/Application Support/Lexi/`，更新沿用原词汇、计划、学习记录、金句、设置及记忆模型；不删除或初始化用户数据。新版本有效时长保存于独立的 `study-activity.json`，旧版没有时长记录时显示“暂无记录”。

适用于 Apple Silicon，macOS 12+；应用包含运行环境、离线词典与本地 FSRS optimizer。仍使用固定分发签名，尚未采用 Developer ID 与 Apple 公证。

## 验证

发布包已通过完整回归、包内隔离验收、严格签名、许可证、隐私及 DMG 完整性检查。冰川蓝专项验收包含 31 项断言，覆盖多次复习与拼写、双语、动画及 840 / 1000 / 1280 宽度的四指标单行布局。源码统计测试 28 项、计划测试 34 项通过。
