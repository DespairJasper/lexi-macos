# Lexi 3.2.3 · macOS

修复每日计划学过的词在次日复习时显示内部标识的问题；其余界面与交互沿用 3.2.2。

## 修复

- 复习页的来源卡（每日计划 / IELTS 单词卡产生的长期记忆卡）在应用启动早期会被装填一次到期队列，此时 IELTS 目录尚未加载完成，词条内容只能按原始标识回退。旧实现把这份回退内容固化在进程内缓存里，目录就绪后也不再重建，于是复习卡一直显示 `vocab:03_动物保护:378` 这类内部 ID，音标与释义为空。
- 3.2.3 起，来源卡的显示内容在每次取用时按当前可用的 IELTS 目录 / 档案补全：到期待复习队列装填、未完成复习轮恢复、撤销与改判共用同一解析路径，目录就绪后复习卡自动显示真实单词、音标与释义。
- 显示内容之外的词身份解析、FSRS 排期、canonical 记录与档案隔离逻辑完全不变；档案词复习卡与形态（form）来源卡行为不变。
- 不修改 `fsrs_cards`、学习轨迹、学习计划 JSON 或任何既有数据；覆盖安装沿用原数据目录、数据库 schema、签名身份与自动更新检查。

## 安装与数据

下载 `Lexi-3.2.3-macOS-arm64.dmg` 和配套 `.sha256`，运行：

```bash
shasum -a 256 -c Lexi-3.2.3-macOS-arm64.dmg.sha256
```

确认OK后先用⌘Q正常退出旧版，再拖入应用程序替换。沿用 `~/Library/Application Support/Lexi/`、数据库schema和签名身份。所有词汇、学习计划、学习轨迹、复习记录、时长、金句、设置及记忆模型均保留。

适用于Apple Silicon、macOS12+，包含运行环境、离线词典与本地optimizer。沿用固定分发签名，尚未采用Developer ID与Apple公证。
