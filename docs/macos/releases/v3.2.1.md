# Lexi 3.2.1 · macOS

修复学习页面布局与金句本双语切换，并隐藏学习计划和统计页面的滚动条。

- 学习与复习答案页的两个按钮左右对称；选择“忘记了”后，只显示的“下一词”按钮居中。三项评分按钮继续等距分布。
- 金句本的导航、标题、搜索提示、添加、导出、分页、编辑及删除操作随中英文即时切换，个人原句、译文、来源、备注与搜索输入保持原样。
- 学习计划、每日计划和学习统计隐藏纵向滚动条，保留滚轮与触控板滚动。

## 安装与数据

下载 `Lexi-3.2.1-macOS-arm64.dmg` 和配套 `.sha256`，进入下载目录运行：

```bash
shasum -a 256 -c Lexi-3.2.1-macOS-arm64.dmg.sha256
```

确认 `OK` 后打开 DMG。先用 `⌘Q` 正常退出旧版，再将 Lexi 拖入应用程序替换。应用继续使用 `~/Library/Application Support/Lexi/`，沿用原有词汇、学习计划、学习记录、金句、设置和记忆模型。本次不修改数据库 schema 或学习数据格式。

适用于 Apple Silicon，macOS 12+；包含运行环境、离线词典与本地 FSRS optimizer。沿用固定分发签名，尚未采用 Developer ID 与 Apple 公证。
