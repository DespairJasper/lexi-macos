Android 首个归档源码基线：Kotlin + Jetpack Compose，包含离线查词、本地词汇档案、固定日期复习、主动 AI、导出与数据基础能力。

本 Release 保存历史源码用于回溯；实际安装优先 Android 0.2.2-alpha。没有把模拟器验收当作所有手机和平板的完整认证。
