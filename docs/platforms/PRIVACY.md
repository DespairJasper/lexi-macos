# 隐私与数据处理说明

Lexi 的词汇档案默认保存在本机。本说明描述当前源码行为，不替代未来商业分发需要的正式隐私政策。

- 离线字典查询不调用 AI，也不需要项目账户。
- AI 由用户在设置选择服务商、接口与模型并主动触发；请求会发送当前词、选中模块及语境偏好。附带来源原句与其他上下文由各端设置控制。请先确认你有权向该服务商发送相关内容。
- 用户承担所配置 AI 服务的费用；项目不能替第三方保证数据留存或训练政策。
- 密钥不进入词条 CSV/PDF；Android 默认仅保留本次运行内存，明确记住后使用 Keystore AES-GCM。Windows 使用本端密钥保护实现。
- Android 使用 PROCESS_TEXT、分享和文件保存器作为系统入口；不通过悬浮窗、无障碍服务持续读取屏幕。应用禁用系统自动备份，仍可主动导出和恢复。
- Windows 具有用户配置的全局快捷键与快速查词入口。剪贴板/选词行为以相应入口和源码为准，不宣称所有第三方应用都提供可读选区。

问题反馈与贡献不要附上真实 API Key、词库、备份、浏览历史、私钥或完整敏感日志。需要复现时构造最小示例，并脱敏路径及个人信息。
