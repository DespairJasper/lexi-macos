# 数据、备份与跨端迁移

## 词条迁移

Windows 1.1.3 起与 Android 0.2.2 使用 29 列 CSV；UTF-8 BOM 便于 Excel/WPS 打开。完整词条可包含 UUID、词义、来源、原句、备注、标签、AI 内容和当前复习进度，不含 API Key。最低两列及旧格式兼容以各端导入实现为准。

推荐先在原端导出 CSV，在另一端使用“导入”入口。重复 UUID/单词按已有规则跳过，不默认覆盖。旧 Windows 格式曾把双语例句以分隔符拼接；原句本身含相同符号时存在歧义，宜使用新版重新导出。

旧 JSON 用于兼容迁移。CSV/JSON 迁移不代表自动同步，也不保证复制全部历史复习流水、Windows FSRS 参数/记忆状态、计划或进行中的会话。

## 整库备份

Windows 默认数据目录为 `%LOCALAPPDATA%\Lexi`；Android 为应用私有目录。整库恢复可能替换当前内容，使用应用内确认和安全副本流程，恢复前再做一次备份。

**不能拿 Windows SQLite 直接覆盖 Android SQLite，反之亦然。** Android 卸载会删除应用私有数据；安装更新需相同应用标识和签名，签名改变可能需要导出后迁移。

## 导出阅读材料

Android 可直接生成多页 A4 PDF，默认复习表与完整档案 PDF 是两种不同内容；也保留系统打印。PDF 用于阅读与打印，不能作为可还原数据库备份。
